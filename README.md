# Luma Album

Luma Album 是一个纯本地运行的 Windows 相册整理工具，用来浏览、整理和检索图片、视频、安卓实况照片与压缩包素材，不会上传用户原文件。

## 功能

- 本地文件夹 / 压缩包统一入口，压缩包内素材可直接浏览
- 按日期、类型、相似素材整理，支持收藏、自定义分类和搜索
- 图片、视频、安卓 Motion Photo 实况预览
- 幻灯片播放、地图地点相簿、文档简单预览
- 图片时间、地点、备注编辑，并写回文件时间与同名 XMP
- 本地缓存缩略图、视频封面和压缩包解压副本
- 支持隐藏文件过滤与 Windows 隐藏属性识别

## 开发

```bash
npm install
npm start
```

## 打包

```bash
npm run dist
```

产物位于 `release/LumaAlbum.exe`，可拷贝到任意电脑直接运行。

## 数据说明

运行数据保存在 exe 同级的 `data/` 目录，包含历史、收藏、设置、编辑记录、智能识别结果、回收站和缓存。`data/cache` 可以安全重建，`data/recycle` 里是真正移出原位置的文件，清理前请确认。
